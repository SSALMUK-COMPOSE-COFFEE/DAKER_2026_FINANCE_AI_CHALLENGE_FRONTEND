# 🔓 풀림 (PULL-LIM)

**묶인 계좌, 근거로 풀립니다.**

보이스피싱(전기통신금융사기) 피해의 여파로 계좌가 부당하게 지급정지된 사람이, 거래 내역을 근거로 은행에 제출할 **소명서(이의제기서)**를 AI와 함께 작성할 수 있도록 돕는 서비스입니다.

React + Vite + Tailwind CSS로 만든 프로토타입입니다.

## 🎯 누구를 위한 서비스인가

당근마켓·번개장터·중고나라 등에서 중고 물품을 정상적으로 판매했는데, 구매자가 입금한 돈이 알고 보니 보이스피싱 피해금이어서 본인 계좌가 **지급정지**된 사람을 대상으로 합니다. 이른바 "3자사기"에 억울하게 연루되어 계좌가 묶인 선의의 피해자가 핵심 타깃입니다.

다음 유형은 서비스 범위에서 제외됩니다.

- 통장협박·통장묶기 피해자 → 별도의 법적 경로 안내로 이탈
- 통장·카드·OTP·비밀번호 등 접근매체를 타인에게 넘긴 경우 → 법률구조공단(132) 등 개인 상담 안내로 이탈

## ✨ 핵심 기능

1. **📋 서비스 소개 · 온보딩** — 서비스 성격과 한계(법률 대리인이 아님, 결과 미보장, 자료는 작성 후 삭제)를 먼저 안내
2. **🩺 상황 진단 (7문항 문진)** — 정지 경위, 접근매체 제공 여부, 거래 플랫폼·물품, 인도 방식, 입금자명 일치 여부, 정지일, 사전 조치 여부를 확인해 서비스 대상 여부와 사안 유형을 판별
3. **⏰ 이의제기 기한(D-day) 자동 계산** — 지급정지일로부터 2개월 이내라는 법정 기한을 기준으로 잔여일을 계산해 상시 노출
4. **📎 증거 업로드 · 완결성 체크리스트** — 진단 답변에 따라 A(거래 실재)·B(물품 인도)·C(계좌 정상성)·D(절차 서류) 카테고리별로 맞춤 증거 목록을 생성하고, 필수 항목 확보율을 게이지로 표시
5. **🔍 AI 분석 결과** — 업로드한 거래 내역을 바탕으로 거래 흐름을 시각화하고, 정상 거래 근거(반복 거래 이력, 세금계산서 대사, 자금 체류 패턴 등)를 구조화해서 제시
6. **📝 소명서 초안 편집** — AI가 생성한 소명서 초안을 문서 에디터에서 직접 수정하거나, 채팅으로 AI에게 재작성을 요청
7. **📮 제출 지원** — 최종 체크리스트와 은행별 제출 창구·연락처 안내로 실제 제출까지 지원

## 📁 프로젝트 구조

- `src/main.tsx` — React 진입점, `src/index.css`를 임포트하고 `src/App.tsx`를 `#root`에 마운트
- `src/App.tsx` — 위 6단계 플로우를 포함한 전체 애플리케이션 로직
- `src/index.css` — 전역 CSS 및 Tailwind CSS v4 임포트
- `index.html` — Vite HTML 셸
- `vite.config.ts` — Vite + React + Tailwind v4 설정 (`@` → `src` 별칭 포함)

## 🚀 실행 방법

### 사전 준비물

- Node.js 22

### 설치 및 실행

```bash
npm install
npm run dev
```

개발 서버가 기본적으로 `8443` 포트에서 실행됩니다. 소스 코드 변경 시 자동으로 반영됩니다(HMR).

### 그 외 스크립트

```bash
npm run build     # 프로덕션 빌드
npm run preview   # 빌드 결과 미리보기
npm run format    # oxfmt로 코드 포맷팅
```

## 🛠️ 기술 스택

- **UI**: React 19, React DOM 19
- **빌드 도구**: Vite 8, TypeScript 5.7, `@vitejs/plugin-react`
- **스타일**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **포맷터**: oxfmt

## ⚠️ 서비스의 한계

- AI는 소명서 초안을 제안할 뿐이며, 최종 지급정지 해제 여부는 은행이 판단합니다.
- 풀림은 법률 대리인이 아니며 결과를 보장하지 않습니다.
- 업로드된 자료는 소명서 작성 목적으로만 사용되며 작성 완료 후 삭제됩니다.
