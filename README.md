# 🔓 풀림 (PULL-LIM)

**묶인 계좌, 근거로 풀립니다.**

보이스피싱(전기통신금융사기) 피해의 여파로 계좌가 부당하게 지급정지된 사람이, 거래 내역과 대화 캡처를 근거로 은행에 제출할 **소명서(이의제기신청서)**를 AI와 함께 작성할 수 있도록 돕는 서비스입니다.

React + Vite + Tailwind CSS로 만든 프론트엔드이며, 자유 서술 분류·이미지 판독·소명서 생성 등 AI 관련 기능은 별도 백엔드 API와 연동해 동작합니다.

## 🎯 누구를 위한 서비스인가

당근마켓·번개장터·중고나라 등에서 중고 물품을 정상적으로 판매했는데, 구매자가 입금한 돈이 알고 보니 보이스피싱 피해금이어서 본인 계좌가 **지급정지**된 사람을 대상으로 합니다. 이른바 "3자사기"에 억울하게 연루되어 계좌가 묶인 선의의 피해자가 핵심 타깃입니다.

다음 유형은 서비스 범위에서 제외됩니다.

- 통장협박·통장묶기 피해자 → 별도의 법적 경로 안내로 이탈
- 통장·카드·OTP·비밀번호 등 접근매체를 타인에게 넘긴 경우, 도박·환치기·대리 인출·송금 등 자기부죄 위험이 있는 경우 → 전문기관 상담 안내로 이탈

## ✨ 핵심 기능

1. **📋 서비스 소개 · 온보딩** — 서비스 성격과 한계(법률 대리인이 아님, 결과 미보장, 자료는 작성 후 삭제)를 먼저 안내
2. **🩺 상황 진단** — 자유 서술을 입력하면 AI가 트랙·유형·적용 조항을 먼저 분류해 답변을 미리 채워주고, 이어지는 13문항으로 확인함. 연락 주체에 따라 은행 길·경찰 길·경보 단계·민사로 분기하고, 금액·입금자명 정합성과 자기부죄 위험 신호를 함께 점검함
3. **⏰ 이의제기 기한(D-day) 자동 계산** — 채권소멸절차 개시 공고 통지를 받았다면 공고일로부터 2개월, 아직 못 받았다면 지급정지일 기준 경과일로 계산해 상시 노출
4. **📎 증거 준비** — 진단 답변에 따라 A(거래 실재)·B(물품 인도)·C(계좌 정상성)·D(절차 서류) 카테고리별 맞춤 증거 목록과 은행별 요구서류·발급 요청문을 제시하고, 완결성을 게이지로 표시함. 거래내역·대화 캡처 이미지는 AI가 직접 읽어 사실관계를 추출하며, 데모용 샘플 데이터로 전 과정을 한 번에 채워볼 수 있음
5. **🔎 입력 내용 확인** — 문진에서 답변한 입금 정보를 정리해서 보여주고, 입금자명 불일치·금액 정합성 여부를 확인함
6. **📝 소명서 초안 편집** — AI가 이의제기신청서 사유란·경위서·증거 인덱스 3종을 생성하며, 문장마다 근거([증거n]·법조문·판례) 출처를 표기함. 신청인 정보를 입력해 서식에 반영하고, AI에게 재작성을 요청하거나 PDF로 내려받을 수 있음
7. **📮 제출 지원** — 제출 체크리스트, 다중 계좌 병렬 제출 안내, 진행 단계(접수→수용→은행 해제→금감원 해제), 은행별 접수처 연락처를 안내함

## 📁 프로젝트 구조

- `src/main.tsx` — React 진입점, `src/index.css`를 임포트하고 `src/App.tsx`를 `#root`에 마운트
- `src/App.tsx` — 위 7단계 플로우를 엮는 전체 애플리케이션 로직
- `src/screens/` — 단계별 화면 컴포넌트(온보딩, 진단, 증거 준비, 입력 내용 확인, 소명서 편집, 제출 지원)
- `src/components/` — 사이드바, 온보딩 모달, 거래 흐름 그래프 등 공용 컴포넌트
- `src/data/` — 문진 문항, 증거 체크리스트 규칙, 은행별 요구서류·발급 요청문 템플릿 등 정적 데이터
- `src/api/` — 백엔드 API 클라이언트 및 타입 정의
- `src/index.css` — 전역 CSS 및 Tailwind CSS v4 임포트
- `index.html` — Vite HTML 셸
- `vite.config.ts` — Vite + React + Tailwind v4 설정(`@` → `src` 별칭, `/api` 프록시 포함)

## 🚀 실행 방법

### 사전 준비물

- Node.js 22
- `.env` 파일 — AI 분류·이미지 판독·소명서 생성 등 대부분의 기능은 별도 백엔드 API 연동이 필요하므로, 이를 위한 환경변수 설정이 선행되어야 합니다(백엔드 자체를 실행하는 방법은 이 저장소의 범위 밖입니다).

### 설치 및 실행

```bash
npm install
npm run dev
```

개발 서버가 기본적으로 `8443` 포트에서 실행됩니다. 소스 코드 변경 시 자동으로 반영됩니다(HMR).

### 그 외 스크립트

```bash
npm run build     # 프로덕션 빌드
npm run preview   # 빌드 결과 미리보기
npm run format    # oxfmt로 코드 포맷팅
```

## 🛠️ 기술 스택

- **UI**: React 19, React DOM 19
- **빌드 도구**: Vite 8, TypeScript 5.7, `@vitejs/plugin-react`
- **스타일**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **아이콘**: lucide-react
- **포맷터**: oxfmt

## ⚠️ 서비스의 한계

- AI는 소명서 초안을 제안할 뿐이며, 최종 지급정지 해제 여부는 은행과 금융감독원이 판단합니다.
- 풀림은 법률 대리인이 아니며 결과를 보장하지 않습니다.
- 업로드된 자료는 소명서 작성 목적으로만 사용되며 작성 완료 후 삭제됩니다.
- AI 문진 분류는 확신도에 따라 일부 문항을 자동으로 채우지 못할 수 있으며, 이 경우 이용자가 직접 답변해야 합니다.
- 은행에 실제로 제출(전자 접수)하는 기능은 없으며, 문서 생성과 제출 안내까지가 서비스 범위입니다.
