Part 1 · As-Is

피해자가 실제로 밟아야 하는 절차

서비스가 없다고 가정했을 때, 무고한 명의인이 지급정지 해제까지 스스로 진행해야 하는 현실의 단계. 제출처는 단 한 곳 — 지급정지된 계좌를 관리하는 은행의 영업점이며, 경찰·금감원은 보조 경로다. 우리 서비스는 이 여정의 3~6번을 대신 정리해주는 것.

1

지급정지 사실·사유 확인 은행

통보 문자·앱 알림 확인 → 은행 콜센터·영업점에 정지 사유(피해구제신청 접수 여부), 정지일, 관련 법조항 문의. 연쇄정지된 타행 계좌가 있는지도 확인.

2

기한 확인 — 이의제기 가능 기간 계산 본인

지급정지일~채권소멸절차 개시 공고일 기준 2개월 이내. 도과 시 채권 소멸 + 전자금융거래제한대상자 지정. 이의제기는 공고를 기다릴 필요 없이 정지일부터 즉시 가능.

3

경찰 신고 — 본인도 사기 피해자로 접수 경찰

사기범(성명불상 구매자)을 상대로 피해 신고·진정 접수 → 접수증·사건사고사실확인원 발급. 의무는 아니지만 '본인도 피해자'라는 D군 증거가 되고, 참고인 조사 대응에도 유리.

4

소명자료 수집 본인 은행

  • A 거래 실재 — 판매 게시글·대화 전체 캡처, 사건 입금 건 내역, 물품 취득원천 증빙
  • B 물품 인도 — 운송장·배송조회, 기프티콘 전송 화면, 직거래 약속 기록
  • C 계좌 정상성 — 입출금 거래내역서(수개월~수년치, 은행 앱·영업점 발급), 재직증명서 또는 고용계약서 택1
  • D 절차 메타 — 정지 통보 캡처, 경찰 접수증, 사기범 정보(더치트 조회)
5

서류 작성 — 제출 패키지 4종 본인

① 이의제기신청서(법정 별지 제4호서식, 사유란 4단 구조) ② 실명확인증표(신분증) ③ 경위서(자유 양식 6단락, 시간순) ④ 소명자료 묶음(증거 번호 별첨). 허위 기재 시 제16조 형사처벌(3년 이하 징역·3천만원 이하 벌금).

6

은행 영업점 방문 제출 은행

본인 방문 원칙(대리 시 위임장·인감 추가). 은행별 자체 양식이 있을 수 있어 방문 전 콜센터 확인 권장. 접수되면 은행은 피해자·금감원에 즉시 통지할 의무.

7

심사 대기 · 보완 대응 은행 금감원

충분한 소명자료 제출 시 5영업일 내 심사결과 통보(2026.5 표준화). 자료 미비 시 보완 요청으로 수 주~수개월 지연. 기각 시 금감원 민원·법률 전문가 경로.

8

인용 후 해제 요청 본인 은행

인용되어도 피해자의 권리주장 대기(최대 2개월)가 있을 수 있고, 은행이 자동 해제해주지 않으므로 기간 경과 후 본인이 직접 해제를 요청해야 여정이 끝난다.

이 여정의 병목 — 1·2번은 정보 부재, 3·4번은 "무엇을 어디서 구하나", 5번은 "사유란을 증거와 엮어 설득력 있게 쓰는 일". 법정 양식 자체는 단순하지만 이 연결 작업이 일반인에게 전문 지식의 장벽이며, 여기가 Part 2 서비스 플로우가 개입하는 지점.

시스템

은행별 제출 안내 + 행동 연결

지급정지 계좌 관리 은행 확인 후 바로 움직일 수 있게 연결: 근처 영업점 찾기(지점·영업시간), 콜센터 원클릭 전화, 문의 스크립트 제공. 자체 양식은 라이브러리에서 이미 반영되므로 "양식 있나요?" 문의는 미커버 은행용 폴백. 디지털 증거는 출력물 제출 + 원본 기기 보존 안내.

본인 방문 원칙, 실명확인증표 지참. 이의제기는 지급정지일부터 즉시 가능 — 공고 대기 불필요.

외부

접수 시 은행의 통지 의무 발생 — 명의인의 소명이 피해자에게 전달되는 유일한 공식 채널.

시스템

세션 데이터 즉시 파기

업로드 자료·분석 결과 파기 실행 및 완료 고지 ('저장하지 않는다' 원칙의 이행 증명).

Part 5 · Questionnaire & Tech Check

문진 설계 예시 & 기술 검증 계획

문진 7문항의 실제 문항·선택지와, 각 답이 플로우의 어느 분기를 결정하는지. 예시 답변은 시연 페르소나 '이서연'(가상) 케이스. 이어서 각 기능을 상용 LLM으로 만들 수 있는지 확인하는 검증 계획.

Q1 · 유형 판별

어떤 상황에서 계좌가 정지되었나요?

중고거래로 물건을 팔고 돈을 받은 후모르는 돈이 입금된 후 협박 메시지를 받음모르는 소액이 입금된 후 (메시지 없음)이유를 전혀 모르겠음
결정하는 것 — 분기 ② 유형 추정: 1번 → 3자사기 경로, 2·3번 → 통장협박·묶기(v2 가이드), 4번 → 통지서 업로드 유도
Q2 · 대상 제외 스크리닝

통장·카드·OTP·비밀번호를 다른 사람에게 준 적이 있나요? (아르바이트·대출 조건 포함)

없음있음
결정하는 것 — 분기 ① 접근매체 양도자 제외: '있음'이면 서비스 대상 아님 안내 후 종료. 민감 문항이므로 "왜 묻는지" 설명 문구 필수
Q3 · 거래 맥락

어디서 무엇을 판매하셨나요?

당근마켓번개장터중고나라기타판매 물품: 아이패드 에어 5 (자유 입력)
예시 답변 — "당근마켓 / 아이패드 에어 5 / 65만 원"
결정하는 것 — 경위서 2단락(판매 경위)의 재료 + 물품 카테고리에 따른 Part 3 추가 자료 분기(전자기기 → 원구매 영수증 권장)
Q4 · 인도 방식

물건은 어떻게 전달하셨나요?

택배 발송직접 만나서 전달기프티콘·핀번호 전송아직 전달 전
결정하는 것 — Part 3 케이스 분기: 택배 → 운송장 필수, 직거래 → 약속 기록, 상품권 → 전송 캡처 + 취득원천. '전달 전'이면 B 명제 없이 A·C 중심 전략으로 전환
Q5 · 시그니처 신호

입금자명이 대화하던 상대의 이름과 같았나요?

같았음달랐음기억나지 않음
예시 답변 — "달랐음. '동생 계좌로 보낸다'고 했음"
결정하는 것 — 3단계 불일치 감지의 사전 신호 + 경위서 3단락의 '당시 인지 상태' 서술 재료. '기억 안 남'이면 업로드된 거래내역에서 자동 대조
Q6 · 기한

계좌가 정지된 날짜가 언제인가요? (통보 문자에 있는 날짜)

2026-08-21 (날짜 선택)모르겠음 → 통지서 캡처 업로드
결정하는 것 — 분기 ③ D-day 계산(D-58). 모르면 통지서에서 자동 추출
Q7 · 사후 조치

경찰 신고나 은행 문의 등 이미 하신 조치가 있나요? (복수 선택)

은행에 전화해봄경찰에 신고함더치트 조회함아직 아무것도 못함
결정하는 것 — D군 증거 확보 여부 + 경위서 4단락(사후 대응) 재료. 미신고자에게는 신고 시 가점 효과 안내
RAG는 어디에 필요한가? — 문진에는 필요 없다. 문진은 선택지 폼 + 규칙 분기라 정확도가 100% 통제된다. RAG가 힘을 쓰는 곳은 4단계 소명서 생성: 우리가 모은 실제 작성례·법조문·금감원 기준(폴더 3번 자료가 시드 코퍼스)에서 유사 사례의 표현·법조 인용을 검색해 근거로 주입하면, LLM이 법 조항을 지어내는 환각을 막고 실무 표준 문구에 정렬된다.

기술 검증 계획 — 상용 LLM으로 되는가?

원칙: LLM이 필요 없는 곳엔 쓰지 않는다(결정론이 곧 정확도). 필요한 곳은 상용 API로 먼저 검증하고, 미달 시 폴백 순서는 프롬프트 개선(few-shot) → RAG 보강 → 파인튜닝 검토.
